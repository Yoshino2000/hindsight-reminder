# 网站与程序提醒

简体中文 · [English](../../README.md)

一个用于 [Hindsight](https://github.com/Tomotsugu-dev/Hindsight) 的提醒插件。设置网站或程序、写下通知内容，进入对应的前台窗口时就会提醒。

## 功能

- **网站与程序规则**：网站按域名匹配，可包含子域名；程序按名称包含或完全相同匹配。
- **自定义通知**：每条规则分别设置内容、启停和冷却时间，也可以暂停全部规则。
- **进入时提醒**：持续停留或窗口标题变化不刷屏；冷却期内离开再进入不重复通知。
- **最近检测**：用实际观察到的应用名称、域名快速填规则，并查看后台心跳和通知状态。
- **本地保存**：关闭设置页后后台仍运行，更新后保留规则与冷却。首次安装没有预置规则。

## 安装

需要 Hindsight **0.10.0 或更新版本**。从 [Releases](https://github.com/Yoshino2000/hindsight-reminder/releases) 下载 `hindsight-reminder-1.0.1.zip`，不要解压。在 Hindsight「设置 → 插件 → 从文件安装」打开文件夹，放入 ZIP、刷新列表，查看权限后安装。

从侧栏打开插件，新增规则并保存。网站检测需要宿主开启「记录浏览器网站域名」。程序规则填写 Hindsight 报告的应用名称，不填文件路径；可以参考页面的「最近检测」。

## 规则怎样触发

- 填完整网址时只提取域名，不区分路径；`www.` 按宿主行为归并。子域名按边界匹配，`example.com.evil.test` 不会当成 `example.com`。
- 程序名忽略大小写及末尾 `.exe`。每条通知最多 500 个字符，冷却默认 60 秒。
- 冷却结束不会补发，需要下次进入才触发。填 0 仍然只在进入时提醒。
- 配置通常在 2 秒内由后台读取。修改或启用规则时，如果后台已有匹配的当前焦点，可能立即提醒。
- 后台重启会保留冷却，但先等待新的焦点事件；旧记录不当作当前前台窗口。

## 权限与数据

申请 `focus.changed`、`focus.app`、`focus.title`、`notifications` 四项权限及 **1 MB** 插件数据库。域名由宿主放在 `focus.title` 权限下，所以安装会标记为高风险；插件匹配只使用程序名和域名，丢弃事件中的窗口标题。

本地数据库保存规则、冷却、最近焦点、各最多 8 个程序和域名、最多 30 次成功的通知 API 调用以及运行状态。插件不联网，不读取宿主历史统计。卸载时可选择是否保留数据。

## 边界与验证

只观察当前前台窗口及浏览器活动标签页，约每 5 秒采样；短暂访问可能漏掉，隐私过滤或采集失败时字段可能为空。Hindsight 退出或插件停用后不再检测。

通知标题固定为插件名，不申请提示音。接口调用成功表示已提交通知，系统权限、勿扰模式仍可能影响展示。请求超时不自动重试，避免重复通知。

这是个人实验插件，未经过严格、全面测试，可能有问题和风险。实际验证范围见[验证记录](../../docs/verification.md)。
